# Битва з монстром з використанням ООП

Перероблено попередню гру з об’єктами та окремими функціями. Правила бою збережено: гравець має 100 HP і силу атаки 20, монстр має 80 HP і силу атаки 15. Гравець ходить першим, живий монстр відповідає.

Клас Character містить спільну логіку атаки, отримання шкоди, показу стану та перевірки життя. Player і Monster наслідують його через extends і super. Здоров’я зберігається у приватному полі #hp, а змінює його метод takeDamage(). У гравця є масив inventory з мечем, щитом і зіллям здоров’я. Використання предметів не додається, оскільки завдання вимагає зберегти попередні механіки.

Після четвертого удару гравця монстр гине й більше не атакує. Результат: гравець має 55 HP, монстр 0 HP; виводиться повідомлення «Гравець переміг!». Значення здоров’я не опускається нижче нуля.

Для запуску потрібен Node.js з підтримкою приватних полів класів. У терміналі VS Code відкрийте папку роботи й виконайте:

```text
node battle.js
```
